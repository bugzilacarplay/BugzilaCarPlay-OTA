New Google Play package

The Google Play version uses the package name com.bugzilacarplay.app and should be treated as the main installation for future public releases.

Important note for existing users

If you installed an older Bugzila Car Play build from the previous package or from direct APK installation, Android may treat the new Google Play build as a different app.

To move to the official Google Play build smoothly, please back up anything important if needed, uninstall the old version, and then install the new version from Google Play.
